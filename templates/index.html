Upload a file to see its detected ISYM symmetry.

Convert half-beam → full-beam

Mirrors the stored C-planes per ISYM and rewrites the header as ISYM=0 (full 0-360° measurement), producing a normalised .LDT you can download.

Export IES (Type C)

Normalises to full-beam first, then writes an IESNA LM-63-2002 Type C file (absolute candela, scaled by the file's total rated lumens).

Compare to Reference (.ies / .ldt)

Compares the loaded LDT against a reference photometric file on a common (C, γ) sampling grid, using bilinear interpolation. Reports candela deviation, flux delta, peak intensity delta and beam-angle delta.

Room Illuminance Heatmap

Duplicates the loaded luminaire on a spacing grid across the room and computes point-by-point illuminance (inverse-square + cosine law) on the work plane, reporting U0 (Emin/Eavg) and U1 (Emin/Emax).

Leave power/efficacy blank to use the file's own declared lumens. Fill in both to recompute total lumens as power × efficacy and rescale the candela solid by (new lumens / file's declared lumens) before running the point-by-point calculation. Reflectances default to the DIALux evo "new project" / EN 12464-1 combination (ceiling 0.70 / walls 0.50 / floor 0.20) and add a room-average interreflected component on top of the direct point-by-point result (Zonal Cavity Method) -- set all three to 0 to get the old direct-only output.
